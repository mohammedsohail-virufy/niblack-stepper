Niblack and Otsu Stepper

Two ways to threshold the same 4×4 class example. Niblack computes a separate threshold for every pixel from its neighbourhood. Otsu picks one threshold for the whole image from the histogram. Press Play, or step through with Back and Next (arrow keys work too).

Made by Mohammed Sohail for MAI621 Computer Vision and Image Processing, Abu Dhabi University. Instructors: Dr. Azza Basiouni and Dr. Syed Gilani. Worked example based on the Topic 5 class notes.

P₁ = n₁ / N, P₂ = n₂ / N = 1 − P₁, m₁ = Σ class-1 values / n₁, m₂ = Σ class-2 values / n₂, with N = 16. Label rule used here, to match the Niblack sheet: output = 1 (dark object) if I ≤ k*.
